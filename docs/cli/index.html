Database CLI reference

psql, mysql, sqlite3, sqlcmd, sqlplus, bq, snowsql, duckdb and clickhouse-client — connection flags, meta-commands and the flags that actually matter.

Every engine ships a terminal client, and each has its own dialect of flags and meta-commands. This page covers the ones you will use daily.

#psql — PostgreSQL

FlagMeaning
-h hostServer host, or a socket directory
-p portPort (default 5432)
-U userRole to connect as
-d dbnameDatabase name
-c "SQL"Run one statement and exit
-f file.sqlRun a script file
-A -tUnaligned output, no headers — for piping to other tools
-F ','Field separator (with -A)
-v ON_ERROR_STOP=1Abort a script on the first error — essential in migrations
-1 / --single-transactionWrap the whole script in one transaction
-EEcho the SQL that meta-commands run — a great way to learn the catalog
-XIgnore ~/.psqlrc (use in scripts for reproducibility)

::: tip Two flags that prevent most migration accidents -v ON_ERROR_STOP=1 makes psql exit non-zero on the first error instead of ploughing on. --single-transaction makes the whole script atomic. Together they turn a half-applied migration into a clean rollback. :::

#mysql — MySQL / MariaDB

FlagMeaning
-h host -P portNote the uppercase -P for port
-u user -pUser; -p prompts (never put the password after it in a shared shell)
-e "SQL"Execute and exit
-B / --batchTab-separated, unquoted output for piping
--tableForce table formatting even when not on a TTY
--vertical / \GOne column per line
--safe-updatesRefuse UPDATE/DELETE without a key in WHERE
--ssl-mode=REQUIREDEnforce TLS

::: warn 127.0.0.1 and localhost are not the same to the mysql client localhost uses a Unix socket; 127.0.0.1 uses TCP. They can resolve to different accounts in the mysql.user table, and one may work while the other is refused. :::

#sqlcmd — SQL Server

FlagMeaning
-S server[,port]Comma before the port, not a colon
-d dbDatabase
-ETrusted (integrated) connection
-Q "SQL" / -q "SQL"Execute and exit / execute and stay
-i in.sql -o out.txtInput and output files
-bReturn a non-zero exit code on error
-s "," -W -h -1CSV-ish output: separator, trim, no header rule

#sqlplus — Oracle

::: warn A trailing slash is not decoration in SQL*Plus A semicolon ends a SQL statement; a lone / on its own line executes the buffer and is required to terminate a PL/SQL block. Scripts fail silently without it. :::
