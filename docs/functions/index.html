Aggregate

12 functions

Collapse many rows into one value.

Syntax
COUNT(*) | COUNT([DISTINCT] expression)
Returns
BIGINT (INT in SQL Server — use COUNT_BIG for > 2^31 rows)
Common use
Row counts, cardinality checks, denominator for percentages, presence tests.
Performance
COUNT(*) on a large table is a full scan in PostgreSQL (MVCC means no stored count). MySQL/InnoDB is also a scan; MyISAM stored it. Use reltuples/table statistics for an approximate count. COUNT(DISTINCT) needs a sort or hash — APPROX_COUNT_DISTINCT / HLL is far cheaper at scale.

Syntax
APPROX_COUNT_DISTINCT(expression)
Returns
BIGINT
Common use
Unique visitor counts, high-cardinality dashboards, anything where 1% error is acceptable.
Performance
Orders of magnitude cheaper than COUNT(DISTINCT) on billions of rows — constant memory instead of a full sort/hash. BigQuery bills the same either way, but the query completes far faster.
