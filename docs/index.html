Why use it?

  • SQL is a standard that no engine implements the same way. Row limiting alone has four spellings.
  • Most references pick one dialect and present it as universal, so what you copy fails somewhere else.
  • Here, where engines differ, every version is shown with the reason for the difference.
  • The traps are called out: NOT IN with NULLs, default window frames, constraints a warehouse does not enforce.

FAQ

Which databases does it cover?

16 engines: PostgreSQL, MySQL, SQLite, SQL Server and Oracle in the most depth, then Redshift, Snowflake, BigQuery, DuckDB, MariaDB, ClickHouse, Trino, Databricks, CockroachDB, Db2 and Synapse. Databases lists them all.

Does the playground send my queries anywhere?

No. The playground runs SQLite inside your browser tab, so your queries and data never leave it. It runs SQLite's dialect, so engine-specific examples for other databases will not run there.

Is it free?

Yes. The whole site is free to read and the source is on GitHub.
