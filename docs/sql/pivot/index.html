Pivot & unpivot

Rows to columns and back: portable conditional aggregation, native PIVOT syntax, and dynamic pivots.

Pivot turns row values into columns. Unpivot does the reverse. Only some engines have dedicated syntax; conditional aggregation works everywhere.

#Dynamic pivots

SQL requires the result's column list to be known at parse time, so a pivot over values discovered at runtime needs generated SQL.

::: danger Dynamic SQL is an injection surface The pivot values come from your data. If a user can insert a row whose quarter is `]) AS p; DROP TABLE sales; --, a naive concatenation executes it. QUOTENAME() (SQL Server), quote_ident()` (PostgreSQL) and parameterised identifiers exist for this reason — always route identifiers through them. :::

::: tip Consider pivoting outside the database Column lists that change with the data fight against SQL's static result shape. BI tools, dataframe libraries and spreadsheet exports all pivot natively and handle the dynamic case without generated SQL. Pivot in SQL when the columns are known and stable. :::
