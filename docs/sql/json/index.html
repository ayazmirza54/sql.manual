JSON in SQL

Storing, extracting, filtering and indexing JSON — the operators differ in every engine, so this is a translation table.

Every major engine now stores and queries JSON, and no two spell it the same way. This page is primarily a translation table.

#Indexing JSON

This is where the engines differ most, and where JSON performance is won or lost.

::: warn JSON is not a substitute for columns A field you filter, join or sort on should be a real column. JSON is for genuinely variable, sparse or write-once payloads. Every engine's JSON path extraction is slower than a column read, most cannot use statistics on JSON internals for cardinality estimation, and constraints/foreign keys cannot reach inside a document. :::
