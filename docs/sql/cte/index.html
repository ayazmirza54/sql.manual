CTEs & recursive queries

WITH clauses for readability, WITH RECURSIVE for hierarchies and graphs, and the optimization-fence question.

A Common Table Expression names a subquery so the main query can reference it — sometimes several times — and so a pipeline reads top to bottom instead of inside out.

#WITH RECURSIVE

A recursive CTE has two parts joined by UNION ALL: an anchor that produces the starting rows, and a recursive term that references the CTE itself and runs repeatedly until it returns nothing.

::: note Syntax note Oracle, SQL Server and Db2 do not use the RECURSIVE keyword — just WITH. PostgreSQL, MySQL, SQLite, MariaDB, BigQuery, Snowflake and Redshift require it. Write WITH RECURSIVE where accepted; it is also documentation for the reader. :::

#Generating series

Engine shortcuts: generate_series() (PostgreSQL, DuckDB, CockroachDB), GENERATE_DATE_ARRAY() (BigQuery), GENERATOR() (Snowflake), numbers() (ClickHouse), sequence() (Trino, Databricks).

MySQL caps iterations at cte_max_recursion_depth (default 1000); SQL Server defaults to OPTION (MAXRECURSION 100). PostgreSQL and SQLite have no default limit — add WHERE depth < n yourself. :::

#Data-modifying CTEs

PostgreSQL lets INSERT/UPDATE/DELETE … RETURNING appear inside a WITH, so a multi-table write becomes one atomic statement.

::: warn All sub-statements see the same snapshot In a data-modifying CTE every branch reads the database as it was at statement start. A SELECT branch will not see rows written by an INSERT branch of the same statement. :::

#Is a CTE an optimization fence?

Whether the engine inlines a CTE into the main query or materializes it once changes plans dramatically.

EngineBehaviour
PostgreSQL ≤ 11Always materialized — a hard optimization fence
PostgreSQL 12+Inlined when referenced once and not recursive; MATERIALIZED / NOT MATERIALIZED force either way
SQL Server, OracleInlined by default; Oracle has /*+ MATERIALIZE / and /+ INLINE */ hints
MySQL 8Materialized into a temporary table in most cases
SQLiteInlined when possible (MATERIALIZED hint available in 3.35+)
BigQuery, Snowflake, RedshiftGenerally inlined; a CTE referenced n times may be executed n times

::: tip A CTE referenced many times may be recomputed many times On warehouses that inline, a CTE used in five places can run five times. If the CTE is expensive, write it to a temporary table instead — and measure, because the opposite (an unnecessary materialization blocking predicate pushdown) is just as common. :::
