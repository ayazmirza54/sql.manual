CREATE

CREATE TABLE, and the vendor clauses that follow it: storage engines, distribution keys, partitioning and CTAS.

CREATE defines objects. The core CREATE TABLE is portable; nearly everything after the closing parenthesis is not.

VariantSyntaxLifetime
TemporaryCREATE TEMPORARY TABLE / CREATE TEMP TABLESession (or transaction with ON COMMIT DROP)
SQL Server tempCREATE TABLE #local / ##globalSession / last session
UnloggedCREATE UNLOGGED TABLE (PostgreSQL)Persists, but not crash-safe or replicated — much faster writes
Global temporaryCREATE GLOBAL TEMPORARY TABLE (Oracle, Db2)Definition permanent, data per session
TransientCREATE TRANSIENT TABLE (Snowflake)Persists, no fail-safe period — cheaper
ExternalCREATE EXTERNAL TABLEMetadata only; data lives in object storage

EngineCTAS syntaxCopies constraints/indexes?
