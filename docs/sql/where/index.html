WHERE & predicates

Filtering rows: comparison, BETWEEN, IN, LIKE, pattern matching, and writing predicates an index can use.

WHERE filters individual rows before grouping. A row survives only when the predicate evaluates to TRUE — FALSE and UNKNOWN are both discarded.

#Comparison operators

OperatorMeaningNotes

< <= > >=OrderingUses the column's collation for text
