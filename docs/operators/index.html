Arithmetic

8
+Addition; also date + interval arithmetic.all
-Subtraction; date difference in some engines.all
*Multiplication.all
/Division. Integer / integer truncates in PostgreSQL, SQL Server, Oracle (no) and Db2; MySQL and SQLite return a float. Division by zero raises an error in PostgreSQL, SQL Server and Oracle; MySQL returns NULL.all
%Modulo (remainder). Oracle uses MOD(a,b) instead.pg, mysql, mssql, sqlite, snowflake, bigquery
^Exponentiation in PostgreSQL; bitwise XOR in MySQL and Oracle. Prefer POWER().pg, duckdb
||/ |/Cube root and square root (PostgreSQL).pg
@Absolute value (PostgreSQL).pg

Comparison

9
=Equality. NULL = NULL is UNKNOWN, not TRUE.all
<> / !=Not equal. <> is the ANSI spelling; != is accepted everywhere.all
< <= > >=Ordering comparison. Text uses the column collation.all
BETWEENInclusive range: a BETWEEN x AND y is a >= x AND a <= y. Inclusive on both ends — a trap with timestamps.all
NOT BETWEENNegated inclusive range.all
IS DISTINCT FROMNULL-safe inequality: TRUE when exactly one side is NULL.pg, db2, duckdb, trino, cockroach, sqlite 3.39+
<=>NULL-safe equality (MySQL, MariaDB, SQLite, Databricks).mysql, mariadb, sqlite, databricks
IS [NOT] TRUE/FALSE/UNKNOWNThree-valued boolean test that never returns UNKNOWN itself.pg, mysql, db2, sqlite
ROW(a,b) = ROW(c,d)Row constructor comparison; compares tuples lexicographically.pg, mysql, sqlite, db2, duckdb

Logical

3
ANDConjunction. Binds tighter than OR.all
ORDisjunction. Parenthesise when mixed with AND.all
NOTNegation. NOT UNKNOWN is UNKNOWN.all

String

4
||String concatenation (ANSI). NULL || x is NULL except in Oracle, where NULL behaves as an empty string.pg, oracle, sqlite, db2, snowflake, duckdb, trino
CONCAT()Portable concatenation. MySQL CONCAT returns NULL if any argument is NULL; CONCAT_WS skips NULLs.all
+String concatenation in SQL Server and Sybase. NULL + x is NULL unless CONCAT_NULL_YIELDS_NULL is off.mssql, synapse
COLLATEOverride the collation for a comparison or sort.pg, mysql, mssql, sqlite, snowflake

Pattern

10
LIKEPattern match. % matches any sequence, _ matches one character.all
NOT LIKENegated pattern match.all
ILIKECase-insensitive LIKE.pg, snowflake, cockroach, duckdb
SIMILAR TOSQL-standard regular expression, halfway between LIKE and POSIX regex.pg, db2
~ ~* !~ !~*POSIX regex match: case-sensitive, case-insensitive, and their negations.pg, cockroach, duckdb
REGEXP / RLIKERegex match.mysql, mariadb, sqlite (if compiled), databricks, clickhouse
REGEXP_LIKE()Function form of regex matching.oracle, mysql 8, db2, snowflake
ESCAPEDefine an escape character so % and _ can be matched literally.all
MATCH … AGAINSTFull-text search against a FULLTEXT index.mysql, mariadb

NULL

5
IS NULLThe only correct test for NULL.all
IS NOT NULLPresence test.all
COALESCE()First non-NULL argument. Short-circuits.all
NULLIF()NULL when the two arguments are equal — the standard divide-by-zero guard.all
IFNULL() / NVL() / ISNULL()Two-argument COALESCE. IFNULL: MySQL/SQLite/BigQuery. NVL: Oracle/Redshift/Db2. ISNULL: SQL Server.varies

Set & subquery

9
INSet membership against a list or subquery.all
NOT INNegated membership. Returns no rows if the set contains NULL — prefer NOT EXISTS. The single most common NULL bug in SQL.all
EXISTSTRUE if the subquery returns at least one row. Semi-join; NULL-safe.all
NOT EXISTSAnti-join. The correct way to express "has no matching row".all
ANY / SOMEQuantified comparison — TRUE if it holds for at least one row. Over an empty set: FALSE.pg, mysql, mssql, oracle, db2, snowflake
ALLTRUE if the comparison holds for every row. Over an empty set: TRUE.pg, mysql, mssql, oracle, db2, snowflake
UNION [ALL]Combine result sets. UNION deduplicates; UNION ALL does not and is much faster.all
INTERSECTRows present in both result sets.pg, mysql 8.0.31+, sqlite, mssql, oracle, snowflake, bigquery
EXCEPT / MINUSRows in the first set but not the second. Oracle spells it MINUS.pg, sqlite, mssql, oracle (MINUS), snowflake, bigquery
