Concatenate two strings

#

|| is the ANSI operator. SQL Server uses +; MySQL reserves || for logical OR unless PIPES_AS_CONCAT is set. CONCAT() works nearly everywhere and is the safest portable choice — but note MySQL CONCAT returns NULL if any argument is NULL, while PostgreSQL and Oracle skip NULLs.

Insert a row, or update it if the key already exists (upsert)

#

MERGE is the ANSI statement (SQL:2003). PostgreSQL and SQLite use ON CONFLICT, MySQL uses ON DUPLICATE KEY UPDATE. All of them require a unique constraint on the conflict target to work correctly under concurrency.

Get the current date and time

#

CURRENT_TIMESTAMP is ANSI and works nearly everywhere. Beware the transactional variants: PostgreSQL now() and Oracle SYSDATE inside a transaction return the transaction start time, not the wall clock.

Add 30 days to a date

#

Interval arithmetic is ANSI; the function forms are not. Adding months clamps to the end of the target month in every engine (31 Jan + 1 month = 28/29 Feb).

#

No portable answer. TO_CHAR covers PostgreSQL, Oracle, Db2, Snowflake and Redshift; MySQL uses DATE_FORMAT with strftime-style codes; SQL Server uses FORMAT or CONVERT with a numeric style.

Return a default when a value is NULL

#

COALESCE is ANSI and works everywhere — the vendor two-argument forms exist only for historical reasons. There is no reason to use NVL, IFNULL or ISNULL in new code.

#

Case-insensitive string comparison

#

MySQL and SQL Server default to case-insensitive collations, so a plain = already works. PostgreSQL and Oracle are case-sensitive by default and need LOWER(), ILIKE, citext, or a non-deterministic collation.

Select 10 random rows

#

Ordering by a random function sorts the entire table — fine on thousands of rows, disastrous on millions. TABLESAMPLE is the ANSI approach and reads only a fraction of the pages.
