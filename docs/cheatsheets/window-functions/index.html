Window Functions cheat sheet

OVER, frames, ranking and offsets — including the frame defaults that cause silent bugs.

sql.manual — Window Functions cheat sheet

All cheat sheets

Anatomy

fn() OVER (PARTITION BY a ORDER BY b frame)Full form
OVER ()Whole result set as one partition
WINDOW w AS (…) … OVER wName and reuse a spec
-- runs after WHERE/GROUP BYso filter on it in a subquery or QUALIFY

Ranking

ROW_NUMBER()1,2,3,4 — ties broken arbitrarily
RANK()1,2,2,4 — ties share, then gap
DENSE_RANK()1,2,2,3 — ties share, no gap
NTILE(4)Quartile buckets by row count
PERCENT_RANK() / CUME_DIST()Relative position 0–1

Offsets

LAG(x [, n [, default]])Previous row
LEAD(x [, n [, default]])Next row
FIRST_VALUE(x)First in the frame
LAST_VALUE(x)⚠ needs an extended frame to be useful
NTH_VALUE(x, 2)nth in the frame

Frames

ROWS BETWEEN 6 PRECEDING AND CURRENT ROW7-row trailing window
ROWS UNBOUNDED PRECEDINGRunning total
ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWINGWhole partition
RANGE BETWEEN INTERVAL '6 days' PRECEDING AND CURRENT ROWTrue time window
-- default with ORDER BYRANGE UNBOUNDED PRECEDING — includes all peers!

Recipes

SUM(x) OVER (ORDER BY d ROWS UNBOUNDED PRECEDING)Running total
AVG(x) OVER (ORDER BY d ROWS BETWEEN 6 PRECEDING AND CURRENT ROW)7-day moving average
x - LAG(x) OVER (ORDER BY d)Period-over-period delta
x / SUM(x) OVER ()Share of total
ROW_NUMBER() OVER (PARTITION BY g ORDER BY d DESC) = 1Latest row per group
SUM(flag) OVER (ORDER BY t ROWS UNBOUNDED PRECEDING)Sessionization / gaps and islands
