Differs from other engines

UNIQUE allows only ONE NULLUnlike every other engine
Default isolation locks readersEnable READ_COMMITTED_SNAPSHOT
Triggers fire per STATEMENT⚠ use the inserted/deleted tables
DATEDIFF counts boundary crossingsNot elapsed time
No LIMIT, no DROP TABLE IF EXISTS < 2016Use TOP and OBJECT_ID checks
MERGE needs WITH (HOLDLOCK)To be concurrency-safe
