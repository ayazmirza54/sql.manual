Query skeleton

SELECT cols FROM tProject columns
WHERE predicateFilter rows (before grouping)
GROUP BY colsCollapse into groups
HAVING agg_predicateFilter groups (after grouping)
ORDER BY col [ASC|DESC]Sort the result
LIMIT n OFFSET mSlice the result
-- evaluation orderFROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT

Filtering

WHERE a = 1 AND b <> 2Equality, inequality
WHERE x BETWEEN 1 AND 10Inclusive range on both ends
WHERE c IN ('DE','FR')Set membership
WHERE s LIKE 'a%'% = any run, _ = one char
WHERE col IS NULLThe only correct NULL test
WHERE NOT EXISTS (SELECT 1 …)Anti-join; NULL-safe

Joins

INNER JOIN b ON b.id = a.b_idMatches on both sides
LEFT JOIN b ON …All left rows; NULLs on the right
RIGHT JOIN b ON …All right rows
FULL OUTER JOIN b ON …All rows from both
CROSS JOIN bCartesian product
JOIN t AS b ON b.mgr = a.idSelf join via aliases
-- filter on the outer tablegoes in ON, not WHERE

Aggregates

COUNT(*)Rows, including all-NULL ones
COUNT(col)Non-NULL values only
COUNT(DISTINCT col)Distinct non-NULL values
SUM / AVG / MIN / MAXNULLs ignored by all four
COUNT(*) FILTER (WHERE …)Conditional count (ANSI)
SUM(CASE WHEN … THEN 1 ELSE 0 END)Portable conditional count

Writes

INSERT INTO t (a,b) VALUES (1,2)Always name the columns
INSERT INTO t SELECT …Insert from a query
UPDATE t SET a = 1 WHERE id = 5Verify with SELECT first
DELETE FROM t WHERE …Row by row, fully logged
TRUNCATE TABLE tFast; not rollbackable in MySQL/Oracle
MERGE INTO t USING s ON …Upsert (SQL:2003)

DDL

CREATE TABLE t (id BIGINT PRIMARY KEY, …)Define a table
ALTER TABLE t ADD COLUMN c TEXTUsually instant
ALTER TABLE t DROP COLUMN cCheck lock behaviour first
CREATE INDEX i ON t (a, b)Composite: equality cols first
CREATE UNIQUE INDEX …Enforces uniqueness
DROP TABLE IF EXISTS tNot available in Oracle

NULL handling

COALESCE(a, b, 0)First non-NULL
NULLIF(a, 0)NULL when equal — divide-by-zero guard
a IS DISTINCT FROM bNULL-safe inequality
NOT IN (subquery with NULL)⚠ always returns zero rows
AVG(col)Divides by non-NULL count, not row count

Set operations

UNIONCombine, remove duplicates (slower)
UNION ALLCombine, keep duplicates (faster)
INTERSECTRows in both
EXCEPTIn the first, not the second (Oracle: MINUS)
