Aggregate

COUNT(*) / COUNT(col) / COUNT(DISTINCT col)Rows / non-NULL / distinct
SUM / AVG / MIN / MAXNULLs ignored
STRING_AGG(x, ',' ORDER BY x)MySQL: GROUP_CONCAT, Oracle: LISTAGG
ARRAY_AGG(x ORDER BY y)PostgreSQL, BigQuery, Snowflake, DuckDB
COUNT(*) FILTER (WHERE …)Portable form: COUNT(CASE WHEN … THEN 1 END)
APPROX_COUNT_DISTINCT(x)HLL — far cheaper at scale

String

CONCAT / CONCAT_WSJoin; _WS skips NULLs
SUBSTRING(s FROM 1 FOR 3)1-based everywhere
LENGTH / LEN / CHAR_LENGTHMySQL LENGTH counts BYTES
TRIM / LTRIM / RTRIMWhitespace or specified chars
REPLACE(s, from, to)Literal, not regex
SPLIT_PART(s, '@', 2)MySQL: SUBSTRING_INDEX
LPAD(s, 8, '0')SQL Server: REPLICATE + RIGHT

Date & time

CURRENT_TIMESTAMP / NOW()SQL Server: SYSDATETIME(); Oracle: SYSTIMESTAMP
DATE_TRUNC('month', ts)MySQL: DATE_FORMAT; SQL Server: DATETRUNC (2022+)
EXTRACT(YEAR FROM d)Universal
d + INTERVAL '30 days'SQL Server: DATEADD(day, 30, d)
DATEDIFF(…)⚠ argument order differs per engine
TO_CHAR(d, 'YYYY-MM-DD')MySQL: DATE_FORMAT; BigQuery: FORMAT_DATE

Conditional & NULL

CASE WHEN … THEN … ELSE … ENDPortable, works everywhere
COALESCE(a, b, c)First non-NULL
NULLIF(a, b)Divide-by-zero guard
GREATEST / LEASTAcross columns in one row
CAST(x AS type) / TRY_CASTTRY_CAST returns NULL on failure
