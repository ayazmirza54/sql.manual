PRAGMAs that matter

PRAGMA foreign_keys = ON⚠ OFF by default, per connection
PRAGMA journal_mode = WALConcurrent readers with one writer
PRAGMA synchronous = NORMALSafe under WAL, much faster
PRAGMA busy_timeout = 5000Wait instead of SQLITE_BUSY
PRAGMA optimizeRun before closing long-lived connections
PRAGMA integrity_checkVerify the file

Type affinity

INTEGER / REAL / TEXT / BLOB / NUMERICThe only five storage classes
Types are advisoryA TEXT column will accept a number
STRICT tables (3.37+)Enforce declared types
INTEGER PRIMARY KEYAliases rowid; auto-assigns
No native DATE/TIME/BOOLEANStore ISO-8601 TEXT or a unix INTEGER

Limits

ALTER TABLE: ADD/DROP/RENAME COLUMN onlyEverything else = table rebuild
No stored proceduresDo it in the host language
No RIGHT/FULL JOIN before 3.39Upgrade or rewrite
One writer at a timeWAL lets readers continue
No GRANT/REVOKESecurity is filesystem permissions
