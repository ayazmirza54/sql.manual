Table design

DISTSTYLE KEY DISTKEY (col)Co-locate joins on this column
DISTSTYLE ALLReplicate small dimension tables everywhere
DISTSTYLE EVENRound-robin — no join co-location
DISTSTYLE AUTORedshift chooses; the modern default
COMPOUND SORTKEY (date, id)Zone-map pruning on leading columns
INTERLEAVED SORTKEY (a, b)Equal weight; expensive to maintain
ENCODE AZ64 / ZSTDColumn compression

Loading

COPY t FROM 's3://…' IAM_ROLE '…' FORMAT CSVThe only fast load path
UNLOAD ('SELECT …') TO 's3://…'Export
Split files ≈ number of slicesParallel load
⚠ Row-by-row INSERTOrders of magnitude slower — avoid
ANALYZE / VACUUM after big loadsRestore statistics and sort order

Diagnostics

SELECT * FROM SVV_TABLE_INFOSkew, unsorted %, size
SELECT * FROM STL_QUERY / SVL_QLOGQuery history
SELECT * FROM STL_ALERT_EVENT_LOGPlanner warnings — start here
SELECT * FROM SVV_DISKUSAGEStorage per slice
EXPLAINLook for DS_BCAST_INNER / DS_DIST_BOTH
