\x auto \timingExpanded output, query timing

Types worth knowing

JSONBIndexable binary JSON — prefer over JSON
TEXTNo penalty vs VARCHAR(n)
TIMESTAMPTZStores an instant; use this, not TIMESTAMP
UUIDNative 16-byte type
INT4RANGE / TSTZRANGE / DATERANGERange types with operators
INET / CIDR / MACADDRValidated network addresses
type[]Arrays, 1-indexed

Index types

B-treeDefault; =, <, >, BETWEEN, ORDER BY
GINJSONB, arrays, full-text
GiSTGeometry, ranges, nearest-neighbour
BRINHuge naturally-ordered tables, tiny index
HashEquality only
CREATE INDEX CONCURRENTLYNon-blocking; cannot run in a transaction
… (col) INCLUDE (payload)Covering index (11+)
… WHERE status = 'open'Partial index

data ->> 'k'Field as text
data #>> '{a,b}'Path as text
data @> '{"k":"v"}'Containment (GIN-indexable)
data ? 'k'Key exists
jsonb_array_elements(x)Array → rows
jsonb_build_object(…)Build a document

Diagnostics

EXPLAIN (ANALYZE, BUFFERS)The plan that matters
SELECT * FROM pg_stat_activityCurrent sessions
SELECT pg_blocking_pids(pid)Who is blocking whom
SELECT * FROM pg_stat_user_tablesSeq scans, dead tuples, vacuum times
SELECT * FROM pg_stat_statements ORDER BY total_exec_time DESCSlowest queries overall
SELECT pg_size_pretty(pg_total_relation_size('t'))Table + index size
SELECT pg_terminate_backend(pid)Kill a connection

Gotchas

Unquoted identifiers fold to lowercaseNever use "CamelCase"
NOT IN with NULLs → zero rowsUse NOT EXISTS
CTEs materialize in ≤ 11Use NOT MATERIALIZED in 12+
Long transactions block vacuumSet idle_in_transaction_session_timeout
Unused replication slot fills the diskMonitor pg_replication_slots
