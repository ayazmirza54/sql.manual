The engines

pgPostgreSQLThe most standards-compliant open-source RDBMS. Extensible types, MVCC, rich indexing.myMySQLThe web's default database. InnoDB storage engine, clustered primary keys, wide hosting support.liteSQLiteAn in-process library, not a server. The most deployed database engine in the world.mssqlSQL ServerMicrosoft's flagship RDBMS. T-SQL procedural dialect, clustered indexes, columnstore.oraOracle DatabaseThe enterprise incumbent. PL/SQL, RAC clustering, deep partitioning and optimizer tooling.rsAmazon RedshiftAWS MPP warehouse forked from PostgreSQL 8.0. Distribution keys and sort keys drive performance.snowSnowflakeSeparates storage from compute. Virtual warehouses, zero-copy cloning, time travel.bqGoogle BigQueryServerless columnar warehouse. No indexes — partitioning, clustering and bytes scanned rule cost.duckDuckDB"SQLite for analytics." In-process vectorized engine that queries Parquet and CSV directly.mariaMariaDBCommunity fork of MySQL. Adds sequences, system-versioned tables and extra storage engines.chClickHouseExtremely fast columnar analytics. MergeTree engines, sparse primary indexes, materialized views.trinoTrino / PrestoA SQL engine with no storage of its own. Queries across catalogs: Hive, Iceberg, PostgreSQL, Kafka.dbxDatabricks SQLANSI-mode Spark SQL over Delta Lake, with Unity Catalog governance and photon vectorization.crdbCockroachDBHorizontally scalable, geo-partitioned SQL with the PostgreSQL wire protocol and serializable isolation.db2IBM Db2IBM's enterprise RDBMS across LUW, z/OS and i. Strong SQL standard coverage and BLU columnar tables.synAzure SynapseMPP T-SQL warehousing on Azure. Distribution strategies replace single-node index tuning.
