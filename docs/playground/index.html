Which engine is this?

SQLite. Its dialect differs from PostgreSQL, MySQL and the warehouses — no RIGHT JOIN before 3.39, no stored procedures, dynamic type affinity, and date()/strftime() instead of DATE_TRUNC. Use the dialect diff to translate anything you write here to another engine.
